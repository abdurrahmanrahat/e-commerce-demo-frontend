# 🌐 Gadgetoria – Modern E-Commerce Platform

### **Live Demo:** https://gadgetoria.vercel.app/

Gadgetoria is a fully responsive, feature-rich e-commerce platform built with **Next.js**, **Shadcn UI**, **Redux Toolkit**, and **MongoDB (API Integrated)**.  
The platform delivers a seamless user experience with advanced product browsing, filtering, cart management, checkout, authentication, and an intuitive **Admin Dashboard** for managing everything from products to reviews.

---

## ⭐ Features Overview

### 🛍️ Customer Side (Frontend)

- Responsive Navbar with Search, Cart & Wishlist
- Homepage with Banner Slider, Categories & Best Selling Products
- Product Listing Page with:
  - Real-Time Search
  - Category Filter
  - Price Range Filter
  - Sort Options
  - Pagination
- Product Details Page:
  - Image Gallery
  - Add to Cart / Buy Now
  - Add to Wishlist
  - Reviews & Rating Summary
  - Related Products
- Cart, Checkout & Order Success
- Coupon Apply Option in Checkout
- Authentication System (Login, Signup)
- Role-Based Authorization (User/Admin)
- User Profile:
  - View Details
  - Edit Profile
  - Theme Toggle (Dark/Light)

---

## 🛠️ Admin Dashboard

### Dashboard Analytics

- Total Orders, Products & Users Overview
- Category-wise Product Chart
- Order Status Chart

### Category Management

- Add Category with Subcategories (Modal Based)
- Category Table with Edit & Delete

### Product Management

- Add New Product
- Product List with Search, Filter & Pagination
- Product Details Modal
- Edit & Delete

### Order Management

- Order Table with Search, Filter & Pagination
- Update Order Status
- View Order Details
- Delete Orders

### Review Management

- Review Table with Search, Filter & Pagination
- Approve / Reject Reviews
- View Full Review Details
- Delete Review
